This repository provides a collection for using HashiCorp Packer to automate the creation of virtual machine templates for VMware vSphere environments.

This project supports the following guest operating systems:

## Linux Distributions

| Operating System  | Version   |
|:------------------|:----------|
| Ubuntu Server     | 24.04 LTS |
| Rocky Linux       | 9         |
| Kylin Server      | 10sp3     |

## Microsoft Windows

| Operating System         | Version | Editions | Experience |
|:-------------------------| :---    | :---     | :---       |
| Microsoft Windows Server | 2019    | Standard | Desktop    |
